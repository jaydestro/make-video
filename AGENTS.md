# Making a video in this checkout

When the user asks to make, resume, or revise a narrated video, or says "I
updated the handoff" about a video, read and follow
[the make-video skill](.github/skills/make-video/SKILL.md) in this session.
Use the user's request as the input; no slash command or separate agent is
necessary. The example renderer is a fixed demo, not a substitute for producing
the requested video.
